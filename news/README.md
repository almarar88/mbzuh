# نبض التقنية — أخبار التقنية والذكاء الاصطناعي

<div align="center"><strong>تطوير Alcode</strong></div>

تطبيق **سطح مكتب لويندوز** متخصص في أخبار التقنية والذكاء الاصطناعي **فقط**.
يجلب الأخبار مباشرة من الإنترنت لحظة طلبها، يعرض كل خبر بتفاصيله الكاملة
وصوره، يترجم ما ليس بالعربية، ويضم **وكيل ذكاء اصطناعي** يبحث ويجمع ويحلّل.

<p align="center"><img src="build/icon.png" width="110" alt="شعار نبض التقنية" /></p>

## ⬇️ التحميل

من [صفحة الإصدارات](https://github.com/almarar88/mbzuh/releases) اختر آخر إصدار
يبدأ بـ `news-v` ونزّل `TechPulse-Setup-1.0.0.exe`، ثم شغّله واتبع خطوات
التثبيت (يُثبَّت للمستخدم الحالي بلا صلاحيات مدير).

> ويندوز قد يُظهر تنبيه «SmartScreen» لأن الملف غير موقّع رقميًا — اختر
> «مزيد من المعلومات» ثم «تشغيل على أي حال».

## ماذا يفعل التطبيق؟

| الميزة | التفاصيل |
|---|---|
| **أخبار تقنية فقط** | مصنّف كلمات مفتاحية (عربي + إنجليزي) يفرز الأخبار إلى «ذكاء اصطناعي» و«تقنية»، ويستبعد ما ليس تقنيًا من المصادر العامة. |
| **جلب مباشر من الإنترنت** | 41 مصدرًا مدمجًا: مواقع عربية (البوابة العربية للأخبار التقنية، عالم التقنية، عرب هاردوير، التقنية بلا حدود)، أخبار Google بالعربية، أشهر المواقع العالمية (TechCrunch، The Verge، Ars Technica، MIT Technology Review، Wired، OpenAI، Google AI، DeepMind، Hugging Face، arXiv…)، 7 مجتمعات Reddit، و8 حسابات على X. ويمكنك إضافة أي خلاصة RSS أو subreddit أو حساب X أو استعلام Google News. |
| **تفاصيل كثيرة لكل خبر** | يفتح صفحة الخبر الأصلية ويستخلص النص الكامل (Readability + JSON-LD)، الصور، الكاتب، وتاريخ النشر، ويعرض معرض صور، وسومًا، أخبارًا ذات صلة، وتصويتات/تعليقات Reddit وإعجابات X. |
| **بالعربية دائمًا** | ما ليس بالعربية يُترجم: العناوين والملخصات تلقائيًا بعد كل تحديث، والنص الكامل عند فتح الخبر. سلسلة مزوّدين: Google (بلا مفتاح) ← MyMemory ← Claude. مع زر للتبديل إلى النص الأصلي. |
| **وكيل ذكاء اصطناعي** | محادثة مع Claude مزوّدة بأدوات: البحث في أخبار التطبيق، قراءة أي رابط، بحث الويب (Bing/DuckDuckGo + بحث Anthropic المدمج)، أخبار Google، Reddit، X، الترجمة، وتحديث المصادر. يجيب بالعربية مع المصادر ويميّز المؤكد من التخمين. |
| **تحليل كل خبر** | زر «حلّل الخبر» يعطي ملخصًا عربيًا، النقاط الرئيسية، لماذا يهم، الكيانات، النبرة، ومستوى التأكيد. بلا مفتاح API يعمل تلخيص استخلاصي محلي. |
| **تحديث تلقائي** | كل 30 دقيقة (قابل للتعديل) مع تنبيه بعدد الأخبار الجديدة، وإزالة المكرر بين المصادر. |

### ماذا يعمل بلا أي مفتاح؟
كل شيء عدا الوكيل والتحليل العميق: الجلب، التصنيف، التفاصيل، الصور، الترجمة
(Google/MyMemory)، البحث، والتلخيص المحلي.

### ماذا يحتاج مفتاحًا؟
- **الوكيل الذكي والتحليل العميق والترجمة بـ Claude**: مفتاح Anthropic API من
  [console.anthropic.com](https://console.anthropic.com/settings/keys)، يوضع في
  الإعدادات. النموذج الافتراضي `claude-opus-5` ويمكن اختيار Sonnet 5 أو Haiku 4.5
  لتقليل التكلفة.
- **X (تويتر)**: لا توجد واجهة مجانية. بلا مفتاح يُجرَّب الجلب عبر نقاط عامة
  (syndication وNitter) وهي **أفضل جهد** وقد تتوقف. مع X Bearer Token
  (developer.x.com) يصبح الجلب موثوقًا.
- **Reddit**: يعمل بلا مفتاح عبر JSON العام ثم RSS، لكن Reddit يحدّ الطلبات لكل
  عنوان IP؛ لذا تُجلب مجتمعاته تسلسليًا بفاصل زمني.

## التشغيل من المصدر

```bash
cd news
npm install
npm run dev          # تشغيل تطويري (Vite + Electron)
npm run typecheck    # فحص الأنواع
npm run build        # بناء ملفات الإنتاج
npm run smoke        # اختبار دخان للخدمات على مصادر حقيقية (بلا Electron)
```

### إنتاج ملف التثبيت لويندوز

```bash
npm run dist:win     # ينتج release/TechPulse-Setup-1.0.0.exe (يُنفَّذ على ويندوز)
npm run dist:win:zip # حزمة مضغوطة تعمل بلا تثبيت (تُبنى من أي نظام)
```

سير عمل جاهز في `.github/workflows/build-news-windows.yml` يبني ملف التثبيت على
`windows-latest` وينشره كإصدار على GitHub — شغّله يدويًا من تبويب **Actions** أو
ادفع وسمًا باسم `news-v1.0.1` مثلًا.

## أين تُحفظ البيانات؟

| المسار (ويندوز) | المحتوى |
|---|---|
| `%APPDATA%\TechPulse\techpulse.db` | قاعدة SQLite: الأخبار، المصادر، الترجمات، المحادثات، الإعدادات (بما فيها المفاتيح) |

لا يُرسل التطبيق أي بيانات إلى خادم خاص به. الاتصالات الخارجية: مصادر الأخبار
التي تختارها، خدمات الترجمة، Anthropic (إن ضبطت مفتاحًا)، وX (إن ضبطت مفتاحًا).

## البنية التقنية

```
news/
├─ electron/            العملية الرئيسية
│  ├─ db/               SQLite (node:sqlite) + المخطط
│  ├─ services/
│  │  ├─ aggregator.ts  محرّك التجميع: جلب → تصنيف → إزالة المكرر → تخزين → تفاصيل → ترجمة
│  │  ├─ rss.ts         محلّل RSS/Atom       · reddit.ts  JSON ثم RSS
│  │  ├─ x.ts           API v2 → syndication → Nitter
│  │  ├─ gnews.ts       أخبار Google + فكّ الروابط الأصلية
│  │  ├─ web.ts         Readability + JSON-LD + تعقيم HTML + الصور
│  │  ├─ classify.ts    مصنّف تقني/ذكاء اصطناعي (عربي + إنجليزي)
│  │  ├─ translate.ts   Google → MyMemory → Claude مع ذاكرة تخزين
│  │  ├─ search.ts      Bing RSS / DuckDuckGo / Google News
│  │  ├─ analyze.ts     تحليل بالنموذج (JSON) أو تلخيص محلي
│  │  ├─ llm.ts         عميل Anthropic SDK
│  │  └─ agent.ts       حلقة أدوات الوكيل مع بث الأحداث
│  └─ ipc/              قنوات الاتصال مع الواجهة
├─ shared/types.ts      الأنواع المشتركة
└─ src/                 واجهة React + Tailwind (RTL، داكن/فاتح)
```

- **Electron 38** + **React 19** + **TypeScript** + **Vite 7** + **Tailwind CSS 4**
- الشبكة عبر `net.fetch` (شبكة Chromium) لتمر من المواقع التي تحجب العملاء غير المتصفحية.
- أمان الواجهة: `contextIsolation` مُفعّل، بلا `nodeIntegration`، جسر IPC محصور
  بقنوات مسموح بها، HTML المقالات يُعقَّم في العملية الرئيسية قبل عرضه، والروابط
  تُفتح في المتصفح الخارجي.
