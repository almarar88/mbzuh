# نبض التقنية — أخبار التقنية والذكاء الاصطناعي

<div align="center"><strong>تطوير Alcode</strong></div>

تطبيق **لأندرويد (APK) ولويندوز** متخصص في أخبار التقنية والذكاء الاصطناعي **فقط**.
يجلب الأخبار مباشرة من الإنترنت لحظة طلبها، يعرض كل خبر بتفاصيله الكاملة
وصوره، يترجم ما ليس بالعربية، ويضم **وكيل ذكاء اصطناعي** يبحث ويجمع ويحلّل.

## ⬇️ التحميل

من [صفحة الإصدارات](https://github.com/almarar88/mbzuh/releases) اختر آخر إصدار
يبدأ بـ `news-v`:

| المنصة | الملف | التثبيت |
|---|---|---|
| **أندرويد** (8.0+) | `TechPulse-news-vX.Y.Z.apk` | افتح الملف على الهاتف وفعّل «تثبيت من مصادر غير معروفة» عند الطلب. |
| **ويندوز** (64-بت) | `TechPulse-Setup-X.Y.Z.exe` | شغّله واتبع الخطوات (بلا صلاحيات مدير). قد يظهر تنبيه SmartScreen — «مزيد من المعلومات» ثم «تشغيل على أي حال». |

### 📱 دعم الهواتف القابلة للطي (Fold)
- **مطويًا** (شاشة ضيقة): شريط تبويبات سفلي (الأخبار، الذكاء الاصطناعي، الوكيل، المحفوظات، المزيد)، عمود واحد للأخبار، وصفحة الخبر بعمود واحد مع لوحة التحليل أسفل النص.
- **مفتوحًا** (شاشة عريضة): شريط جانبي كامل، شبكة أخبار بعمودين أو أكثر، وصفحة الخبر بعمودين (النص + لوحة التحليل).
- الانتقال بين الحالتين فوري بلا إعادة تشغيل: النشاط مُعلَن `resizeableActivity` ويعالج تغيّر حجم الشاشة والكثافة بنفسه، والواجهة تستجيب لـ media queries لحظيًا. الهوامش تحترم شريط الحالة والتنقل (safe areas) في وضع الحافة إلى الحافة.

## ماذا يفعل التطبيق؟

| الميزة | التفاصيل |
|---|---|
| **أخبار تقنية فقط** | مصنّف كلمات مفتاحية (عربي + إنجليزي) يفرز الأخبار إلى «ذكاء اصطناعي» و«تقنية»، ويستبعد ما ليس تقنيًا من المصادر العامة. |
| **جلب مباشر من الإنترنت** | 41 مصدرًا مدمجًا: مواقع عربية (البوابة العربية للأخبار التقنية، عالم التقنية، عرب هاردوير، التقنية بلا حدود)، أخبار Google بالعربية، أشهر المواقع العالمية (TechCrunch، The Verge، Ars Technica، MIT Technology Review، Wired، OpenAI، Google AI، DeepMind، Hugging Face، arXiv…)، 7 مجتمعات Reddit، و8 حسابات على X. ويمكنك إضافة أي خلاصة RSS أو subreddit أو حساب X أو استعلام Google News. |
| **تفاصيل كثيرة لكل خبر** | يفتح صفحة الخبر الأصلية ويستخلص النص الكامل (Readability + JSON-LD)، الصور، الكاتب، وتاريخ النشر، ويعرض معرض صور، وسومًا، أخبارًا ذات صلة، وتصويتات/تعليقات Reddit وإعجابات X. |
| **بالعربية دائمًا** | ما ليس بالعربية يُترجم: العناوين والملخصات تلقائيًا بعد كل تحديث، والنص الكامل عند فتح الخبر. سلسلة مزوّدين: Google (بلا مفتاح) ← MyMemory ← Claude. مع زر للتبديل إلى النص الأصلي. |
| **وكيل ذكاء اصطناعي** | محادثة مع Claude مزوّدة بأدوات: البحث في أخبار التطبيق، قراءة أي رابط، بحث الويب (Bing/DuckDuckGo + بحث Anthropic المدمج)، أخبار Google، Reddit، X، الترجمة، وتحديث المصادر. يجيب بالعربية مع المصادر ويميّز المؤكد من التخمين. |
| **تحليل كل خبر** | زر «حلّل الخبر» يعطي ملخصًا عربيًا، النقاط الرئيسية، لماذا يهم، الكيانات، النبرة، ومستوى التأكيد. بلا مفتاح API يعمل تلخيص استخلاصي محلي. |
| **تحديث تلقائي** | كل 30 دقيقة (قابل للتعديل) مع تنبيه بعدد الأخبار الجديدة، وإزالة المكرر بين المصادر. على أندرويد: سحب للتحديث، وتحديث عند العودة للتطبيق، وتنبيهات محلية بالأخبار الجديدة. |
| **تنبيهات حقيقية** | على أندرويد: عامل خلفية أصلي (WorkManager) يجلب الخلاصات المفعّلة والتطبيق **مغلق** كل فترة التحديث (الحد الأدنى 15 دقيقة)، ويرسل تنبيهًا مفصّلًا لكل خبر يطابق اهتماماتك (قناة عالية الأولوية) وملخصًا بالأخبار الجديدة (قناة عادية)، والنقر يفتح الخبر داخل التطبيق. على ويندوز: تنبيهات سطح المكتب عند وجود أخبار جديدة والنافذة في الخلفية. |
| **ويدجت الشاشة الرئيسية** | قائمة بأحدث الأخبار (العناوين المترجمة من التطبيق، شارة AI/تقنية، المصدر والوقت، صورة مصغّرة)، قابلة لتغيير الحجم، بزر تحديث، والنقر على خبر يفتحه في التطبيق. تتحدّث مع كل جلب سواء من التطبيق أو من عامل الخلفية. |
| **اهتماماتي** | كلمات وجهات تهمّك تُبرز في الخلاصة بشارة ⭐، ومرشح «اهتماماتي»، وتنبيه عند ورود أخبار عنها. وكلمات مكتومة تُخفي ما لا تريده. |
| **تحليلات الأسبوع** | صفحة برسم بياني لعدد الأخبار يوميًا، نسبة AI، أهم المصادر، المواضيع الأكثر تداولًا، وحسب نوع المصدر. |
| **ترتيب ومرشحات** | الأحدث / الرائج / الأكثر تفاعلًا، عربي أصلي فقط، غير المقروء، وسم من «الأكثر تداولًا»، وتعليم الكل كمقروء. |
| **قراءة أذكى** | وقت القراءة، استماع للخبر بصوت عربي، مشاركة (نظام أندرويد أو الحافظة)، عرض مضغوط، حجم خط، إخفاء الصور لتوفير البيانات، مظهر تلقائي/كريمي/داكن، وتصدير المحفوظات بصيغة Markdown. |
| **أسئلة سريعة للوكيل** | من صفحة الخبر: لماذا يهم؟ اشرح ببساطة، رأي المجتمع، تغطيات أخرى. ومن البحث الفارغ: ابحث في الويب عبر الوكيل. |

### ماذا يعمل بلا أي مفتاح؟
كل شيء عدا الوكيل والتحليل العميق: الجلب، التصنيف، التفاصيل، الصور، الترجمة
(Google/MyMemory)، البحث، والتلخيص المحلي.

### ماذا يحتاج مفتاحًا؟
- **التنبيهات في الخلفية على أندرويد**: تعمل بلا مفاتيح، لكن النظام قد يؤخرها حسب حالة البطارية؛ استثنِ التطبيق من «تحسين البطارية» لضمان الانتظام. عامل الخلفية يجلب خلاصات المواقع وأخبار Google فقط (بلا ترجمة)، والترجمة والتحليل يكتملان عند فتح التطبيق.
- **الوكيل الذكي والتحليل العميق والترجمة بـ Claude**: مفتاح Anthropic API من
  [console.anthropic.com](https://console.anthropic.com/settings/keys)، يوضع في
  الإعدادات. النموذج الافتراضي `claude-opus-5` ويمكن اختيار Sonnet 5 أو Haiku 4.5
  لتقليل التكلفة.
- **X (تويتر)**: لا توجد واجهة مجانية. بلا مفتاح يُجرَّب الجلب عبر نقاط عامة
  (syndication وNitter) وهي **أفضل جهد** وقد تتوقف. مع X Bearer Token
  (developer.x.com) يصبح الجلب موثوقًا.
- **Reddit**: يعمل بلا مفتاح عبر JSON العام ثم RSS، لكن Reddit يحدّ الطلبات لكل
  عنوان IP؛ لذا تُجلب مجتمعاته تسلسليًا بفاصل زمني.

## التشغيل من المصدر

```bash
cd news
npm install
npm run dev          # تشغيل تطويري (Vite + Electron)
npm run typecheck    # فحص الأنواع
npm run build        # بناء ملفات الإنتاج
npm run smoke        # اختبار دخان للخدمات على مصادر حقيقية (بلا Electron)
```

### إنتاج APK لأندرويد

```bash
npm run android:apk  # يبني الواجهة، يزامن Capacitor، ويشغّل gradlew assembleRelease
# الناتج: android/app/build/outputs/apk/release/app-release.apk
```

يتطلب JDK 17+ وAndroid SDK (platform 35 + build-tools 35). سير عمل جاهز في
`.github/workflows/build-news-android.yml` يبني الـAPK على GitHub وينشره مع
الإصدار. **التوقيع**: يُستخدم مفتاح تطوير مرفق في `android/app/keystore/`
كي يبقى التوقيع ثابتًا بين الإصدارات (فتنجح الترقية دون حذف التطبيق). للنشر
العام ضع مفتاحك في أسرار GitHub: `ANDROID_KEYSTORE_BASE64`،
`ANDROID_KEYSTORE_PASSWORD`، `ANDROID_KEY_ALIAS`، `ANDROID_KEY_PASSWORD`.

### إنتاج ملف التثبيت لويندوز

```bash
npm run dist:win     # ينتج release/TechPulse-Setup-1.0.0.exe (يُنفَّذ على ويندوز)
npm run dist:win:zip # حزمة مضغوطة تعمل بلا تثبيت (تُبنى من أي نظام)
```

سير عمل جاهز في `.github/workflows/build-news-windows.yml` يبني ملف التثبيت على
`windows-latest` وينشره كإصدار على GitHub — شغّله يدويًا من تبويب **Actions** أو
ادفع وسمًا باسم `news-v1.0.1` مثلًا.

## أين تُحفظ البيانات؟

| المسار | المحتوى |
|---|---|
| ويندوز: `%APPDATA%\TechPulse\techpulse.db` | قاعدة SQLite: الأخبار، المصادر، الترجمات، المحادثات، الإعدادات (بما فيها المفاتيح) |
| أندرويد: بيانات التطبيق الخاصة `techpulse.db` | القاعدة نفسها (sql.js) تُحفظ في تخزين التطبيق الخاص، وتُحذف مع إلغاء التثبيت |

لا يُرسل التطبيق أي بيانات إلى خادم خاص به. الاتصالات الخارجية: مصادر الأخبار
التي تختارها، خدمات الترجمة، Anthropic (إن ضبطت مفتاحًا)، وX (إن ضبطت مفتاحًا).

## البنية التقنية

```
news/
├─ core/                المنطق المشترك بين أندرويد وويندوز (بلا اعتماد على Node)
│  ├─ db.ts             واجهة قاعدة البيانات + المخطط
│  ├─ platform.ts       نقاط الالتصاق بالمنصة (تحليل HTML، البيئة)
│  └─ services/
│     ├─ aggregator.ts  محرّك التجميع: جلب → تصنيف → إزالة المكرر → تخزين → تفاصيل → ترجمة
│     ├─ rss.ts         محلّل RSS/Atom       · reddit.ts  JSON ثم RSS
│     ├─ x.ts           API v2 → syndication → Nitter
│     ├─ gnews.ts       أخبار Google + فكّ الروابط الأصلية
│     ├─ web.ts         Readability + JSON-LD + تعقيم HTML + الصور
│     ├─ classify.ts    مصنّف تقني/ذكاء اصطناعي (عربي + إنجليزي)
│     ├─ translate.ts   Google → MyMemory → Claude مع ذاكرة تخزين
│     ├─ search.ts      Bing RSS / DuckDuckGo / Google News
│     ├─ analyze.ts     تحليل بالنموذج (JSON) أو تلخيص محلي
│     ├─ llm.ts         عميل Anthropic SDK
│     └─ agent.ts       حلقة أدوات الوكيل مع بث الأحداث
├─ electron/            ويندوز: node:sqlite + linkedom + net.fetch + قنوات IPC
├─ android/             مشروع Capacitor لأندرويد (Gradle)
│  └─ app/src/main/java/com/alcode/techpulse/
│     ├─ TechPulsePlugin.java     جسر Capacitor: مزامنة الويدجت/الإعدادات، جدولة WorkManager
│     ├─ NewsFetchWorker.java     عامل الخلفية: جلب RSS، تصنيف مبسّط، تنبيهات، تحديث الويدجت
│     ├─ NewsWidgetProvider.java  ويدجت الشاشة الرئيسية (قائمة + رأس + تحديث)
│     └─ NewsWidgetService.java   مزوّد عناصر الويدجت من widget.json مع صور مصغّرة
├─ shared/types.ts      الأنواع المشتركة
└─ src/                 واجهة React + Tailwind (RTL، داكن/فاتح، متجاوبة)
   └─ platform/         أندرويد/الويب: sql.js + CapacitorHttp + Filesystem + Browser
```

- **Electron 38** + **Capacitor 7** + **React 19** + **TypeScript** + **Vite 7** + **Tailwind CSS 4**
- الواجهة واحدة للمنصتين: في Electron تتصل بالعملية الرئيسية عبر IPC، وعلى أندرويد تشغّل
  الخدمات نفسها داخل WebView مع SQLite بـ WASM وطلبات شبكة أصلية عبر CapacitorHttp (بلا CORS).
- على ويندوز الشبكة عبر `net.fetch` (شبكة Chromium) لتمر من المواقع التي تحجب العملاء غير المتصفحية.
- أمان الواجهة: `contextIsolation` مُفعّل، بلا `nodeIntegration`، جسر IPC محصور
  بقنوات مسموح بها، HTML المقالات يُعقَّم في العملية الرئيسية قبل عرضه، والروابط
  تُفتح في المتصفح الخارجي.
