## ⬇️ التحميل

**[تحميل ملف التثبيت لويندوز (64-بت)](https://github.com/almarar88/mbzuh/releases/download/v2.0.0/MBZUH-Admin-Setup-2.0.0.exe)**

أو من [صفحة الإصدارات](https://github.com/almarar88/mbzuh/releases) لاختيار إصدار محدد.

بعد التنزيل: شغّل `MBZUH-Admin-Setup-2.0.0.exe` واتبع خطوات التثبيت (يُثبَّت للمستخدم
الحالي بلا صلاحيات مدير)، ثم افتح **منصّة الإداري** من قائمة ابدأ أو من أيقونة سطح المكتب.

> ملاحظة: ويندوز قد يُظهر تنبيه «SmartScreen» لأن ملف التثبيت غير موقّع رقميًا —
> اختر «مزيد من المعلومات» ثم «تشغيل على أي حال».

## ما الجديد في الإصدار 2.0

### 🌐 لوحة نظام الجامعة الموحّد (UMS) داخل التطبيق

- الرابط `https://ums.mbzuh.ac.ae` يُعرض داخل التطبيق في **جلسة دائمة** تحفظ تسجيل
  الدخول (Microsoft Azure أو UAE PASS) بين مرات التشغيل.
- **مظهر حديث** يُحقن كأنماط CSS فوق واجهة الموقع (المبنية على Bootstrap 4): خط
  Tajawal، أزرار وحقول بزوايا ناعمة وظلال، جداول بترويسة ثابتة وتظليل عند المرور،
  صفحة دخول زجاجية، وحركات دخول لطيفة. لا يغيّر أي منطق أو بيانات في النظام،
  ويمكن الرجوع للمظهر الأصلي بضغطة زر.
- **وضع داكن** اختياري للوحة، تكبير/تصغير، رجوع/تقدّم/إعادة تحميل، فتح في المتصفح،
  ومسح الجلسة (تسجيل خروج).
- الروابط الخارجية تُفتح في متصفح النظام؛ نطاقات الجامعة وتسجيل الدخول تبقى داخل اللوحة.

### ✨ المساعد الذكي (Claude API)

يعمل من **الإعدادات ← المساعد الذكي** بعد إدخال مفتاح Claude API (يُخزَّن مشفّرًا على
الجهاز عبر DPAPI ولا يُرسل إلا إلى Claude).

- **محادثة بأدوات**: يقرأ بيانات التطبيق عند الحاجة (لوحة المؤشرات، البحث في كل
  السجلات، تعارضات الجدول، المهام، المحاضر، الدورات) و**يُنشئ مهامًا** مباشرة في
  لوحة المهام. الردود تُبثّ تدريجيًا، مع إظهار الأدوات التي استُخدمت، وسجل محادثات محفوظ.
- **أدوات مهام جاهزة**: خطاب/مذكرة رسمية، بريد إلكتروني (صياغة أو ردّ)، تنظيم محضر
  اجتماع، تلخيص، ترجمة رسمية عربي⇄إنجليزي، تدقيق لغوي، خطة أسبوعية، تقرير سردي
  من أرقام، تعميم/إعلان — مع نسخ المخرج أو حفظه كملف.
- **استخراج المهام**: من أي محضر في الأرشيف بضغطة واحدة، أو من نص ملصوق، أو
  **تفكيك هدف كبير** إلى خطوات بأولويات وتواريخ (مخرجات مهيكلة JSON).
- اختيار النموذج (Opus 5 افتراضيًا، Sonnet 5، Haiku 4.5، Fable 5.1) وعمق التفكير،
  واسم المستخدم ومسماه للتوقيع في المراسلات.

### ✅ لوحة المهام

Kanban بثلاثة أعمدة (للتنفيذ / قيد العمل / منجز) بسحب وإفلات، أولويات ملوّنة،
تواريخ استحقاق مع تنبيه للمتأخر والمستحق اليوم، وسوم، وإحصاءات فورية. عداد المهام
المفتوحة يظهر في الشريط الجانبي وفي «تركيز اليوم» على الرئيسية.

### 🎨 تصميم جديد

هوية بألوان الجامعة (ذهبي على كحلي) مع وضع فاتح، خط Tajawal مضمّن، شريط جانبي
زجاجي بأيقونات خطية، بطاقة ترحيب حسب الوقت مع اختصارات، عدّادات متحركة، هياكل
تحميل، وحركات دخول متدرجة. التاريخ الميلادي والهجري والوقت في الشريط الجانبي.

اختصارات: `Ctrl+K` بحث شامل وإجراءات سريعة · `Ctrl+J` المساعد · `Ctrl+2` لوحة UMS ·
`Ctrl+4` المهام · `Ctrl+Shift+T` مهمة جديدة.

## الوحدات الأكاديمية (مستمرة من الإصدار الأول)

| الوحدة | ماذا تفعل |
|---|---|
| **سجل المدربين** | ملف لكل مدرب: التخصص اللغوي، أوقات الفراغ الأسبوعية، المناهج، نوع التعاقد وبيانات التواصل. |
| **منسق المستويات** | خطة كل دورة: اللغة والمستوى، المدرب، القاعة، التواريخ، الطاقة الاستيعابية، والحصص الأسبوعية. |
| **كاشف التعارض** | تنبيه فوري (أحمر) لتعارض القاعة أو المدرب، و(برتقالي) لموعد خارج فراغ المدرب أو قاعة تحت الصيانة. |
| **الشركاء والقاعات** | سجل الجهات الخارجية بمستنداتها ومرفقاتها، وإشغال القاعات اليومي وحجوزات الجهات مع فحص تعارض. |
| **الطلبة والحضور** | رصد حضور يومي، واستيراد إكسل/CSV للتسجيل والحضور بتعرّف تلقائي على الأعمدة. |
| **مولّد التقارير** | تقارير PDF وExcel أكاديمية مع فلتر يستبعد أي بيانات مالية عند الاستيراد والتصدير. |
| **أرشيف المحاضر** | نموذج محضر سريع مرتبط بالمدربين، بحث فوري بتطبيع النص العربي، واستخراج المهام بالذكاء الاصطناعي. |

## التشغيل والبناء

المتطلبات: [Node.js 22](https://nodejs.org) أو أحدث. لا يحتاج التطبيق إلى أدوات ترجمة
C++ لأن قاعدة البيانات تستخدم `node:sqlite` المدمجة في Electron.

```bash
npm install

npm run dev          # تشغيل في وضع التطوير
npm run typecheck    # فحص الأنواع
npm run build        # بناء ملفات الإنتاج
npm run icon         # إعادة توليد أيقونة التطبيق من رسم SVG
```

### إنتاج ملف التثبيت لويندوز

```bash
npm run dist:win     # ينتج release/MBZUH-Admin-Setup-2.0.0.exe (يُنفَّذ على ويندوز)
npm run dist:win:zip # ينتج حزمة مضغوطة تعمل بلا تثبيت (تُبنى من أي نظام)
```

- سير عمل جاهز في `.github/workflows/build-windows.yml` يبني ملف التثبيت على
  `windows-latest` وينشره كإصدار على GitHub — شغّله يدويًا من تبويب **Actions**
  بوسم مثل `v2.0.1`، أو ادفع وسمًا يبدأ بـ`v`.

## أين تُحفظ البيانات؟

| المسار (ويندوز) | المحتوى |
|---|---|
| `%APPDATA%\MBZUH Admin\mbzuh.db` | قاعدة البيانات (SQLite): الوحدات، المهام، سجل محادثات المساعد |
| `%APPDATA%\MBZUH Admin\backups\` | النسخ الاحتياطية (تلقائية يوميًا + يدوية) |
| `%APPDATA%\MBZUH Admin\files\` | مرفقات الشركاء والمحاضر |
| `%APPDATA%\MBZUH Admin\Partitions\` | جلسة لوحة UMS (ملفات تعريف الارتباط) |

لا يُرسل التطبيق أي بيانات إلى أي خادم باستثناء: (1) طلبات المساعد الذكي إلى
Claude API عند استخدامه، و(2) اتصال لوحة UMS بموقع الجامعة داخل التطبيق.

## البنية التقنية

```
├─ electron/            العملية الرئيسية
│  ├─ db/               الاتصال بقاعدة البيانات + المخطط + البيانات التجريبية
│  ├─ services/         ai (Claude) · ums (اللوحة المدمجة والمظهر) · tasks · التعارض · التقارير · الاستيراد
│  └─ ipc/              قنوات الاتصال مع الواجهة (assistant: المساعد/المهام/UMS)
├─ shared/              أنواع وأدوات مشتركة
├─ src/                 واجهة React + Tailwind (١٣ شاشة، خط Tajawal مضمّن)
└─ build/               أيقونة التطبيق
```

- **Electron 38** + **React 19** + **TypeScript** + **Vite 7** + **Tailwind CSS 4**
- الذكاء الاصطناعي: **@anthropic-ai/sdk** (بث تدريجي، أدوات، مخرجات مهيكلة، تفكير تكيفي)
- لوحة UMS: **WebContentsView** بجلسة `persist:` وحقن CSS عبر `insertCSS`
- قاعدة البيانات: **SQLite** عبر `node:sqlite` (بلا وحدات أصلية)
- أمان الواجهة: `contextIsolation` مُفعّل، بلا `nodeIntegration`، جسر IPC محصور
  بقائمة قنوات مسموح بها، ومفتاح API مشفّر بـ`safeStorage`.
