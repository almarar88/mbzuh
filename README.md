## المزايا

### 🌐 البوابات الجامعية (جلسة دخول واحدة)

سبع بوابات جاهزة ويمكن إضافة غيرها من الإعدادات:

| البوابة | الرابط | الاستخدام |
|---|---|---|
| نظام الجامعة الموحّد UMS | ums.mbzuh.ac.ae | الطلبة والتسجيل والشؤون الأكاديمية |
| لوحة الدورات Hub | hub.mbzuh.ac.ae/cecadmin | إدارة دورات مركز التعليم المستمر |
| البريد Outlook | outlook.office.com | المهام والمراسلات |
| Microsoft Teams | teams.microsoft.com | الاجتماعات ومواعيدها |
| SharePoint | mbzuh.sharepoint.com | الملفات والسياسات |
| OneHub | onehub.gov.ae | الإجازات والخدمات الحكومية |
| موقع الجامعة | mbzuh.ac.ae | الأخبار والتعاميم |

- **جلسة دائمة** تحفظ تسجيل الدخول (مايكروسوفت الموحّد / UAE PASS) بين مرات التشغيل.
- **شهادات الأنظمة الداخلية**: إن كان موقع جامعي (مثل Hub) يستخدم شهادة أمان غير
  موثوقة على الجهاز، تظهر بطاقة تشرح المشكلة مع زر «الوثوق بالشهادة والمتابعة» لهذا
  الموقع تحديدًا، ورسائل أخطاء الاتصال بالعربية.
- **بيانات دخول محفوظة** لكل بوابة مع **تعبئة تلقائية** لصفحات الدخول (تدعم صفحات
  مايكروسوفت ذات الخطوتين). تُخزَّن مشفّرةً بـDPAPI على ويندوز ولا تُعرض للمساعد أبدًا؛
  خطوات التحقق الثنائي تبقى بيدك.
- **مظهر حديث** يُحقن كأنماط فوق الموقع (خط Tajawal، أزرار وحقول وجداول حديثة، وضع
  داكن) مع إمكانية الرجوع للمظهر الأصلي — مفعّل افتراضيًا لـUMS وHub.
- على ويندوز تُعرض البوابات داخل التطبيق بتبويبات؛ على أندرويد تُفتح في متصفح
  أصلي داخل التطبيق بنفس الجلسة والمظهر.

### ✨ المساعد الذكي (Claude API)

- **محادثة بأدوات** تقرأ بيانات التطبيق (المهام، المحاضر، الدورات…) وتُنشئ المهام
  وتحدّثها، مع **بحث في الإنترنت** لجلب المعلومات.
- **المساعد داخل البوابة**: شريط أوامر بجانب كل بوابة مفتوحة (وعلى أندرويد داخل شاشة
  البوابة نفسها) — اكتب «لخّص هذه الرسالة»، «حوّل الطلبات هنا إلى مهام»، «اكتب مسودة
  رد» فيُنفَّذ على الصفحة الحالية مباشرة.
- **التحكم في البوابات** (ويندوز وأندرويد): يفتح البوابة، يقرأ الصفحة (النص، الجداول،
  الروابط، الحقول، رسائل البريد)، ينقر ويعبّئ الحقول، ويلتقط لقطة — مثل: «لخّص بريدي
  غير المقروء وحوّله إلى مهام»، «ما اجتماعاتي اليوم في Teams؟»، «ابحث في SharePoint
  عن سياسة الإجازات». أزرار الإرسال/الحذف/الاعتماد تتطلب موافقتك دائمًا.
- **موجز اليوم** على الرئيسية: يجمعه المساعد من بريدك وتقويمك ومهامك (أهم الأولويات،
  ما يحتاج ردًا، المتأخر) ويُحفظ لليوم.
- **روتينات ذكية**: أوامر محفوظة تُنفَّذ بنقرة أو تلقائيًا في وقت محدد يوميًا (موجز
  الصباح، بريد ← مهام، اجتماعات الغد، متابعة الدورات) مع إشعار بالنتيجة.
- **ذاكرة**: يحفظ المساعد حقائق مفيدة عنك وعن عملك (مديرك، الجهات التي تتابعها،
  تفضيلاتك) ويستخدمها في كل محادثة؛ تديرها من الإعدادات.
- **مرفقات**: أرفق PDF أو Word أو Excel أو PowerPoint أو صورة (اختيار، لصق، أو سحب)
  واطلب تلخيصه أو استخراج المهام أو ترجمته. الردود تُعرض منسّقة (عناوين، قوائم، جداول).
- **ترابط**: المهام المستخرجة من البريد تحمل رابط الرسالة (زر «المصدر» يفتحها في
  البوابة)، وكل مهمة لها زر «المساعد»، والبحث السريع (Ctrl+K) يشمل المهام والبوابات
  وإجراءات سريعة، وأجندة اليوم تجمع المهام وحصص الدورات والحجوزات، ومركز التنبيهات
  (الجرس) يجمع المتأخر والمستحق والتعارضات ونتائج الروتينات والتحديثات.
- **تقارير**: تقرير إنجاز أسبوعي من مهامك بنقرة، وتصدير المهام إلى Excel.

### 🛡️ جاهزية واستقرار

- معالج أول تشغيل (المفتاح، الاسم، البوابات، التحكم) في أربع خطوات.
- فحص صحة النظام من الإعدادات (المفتاح، القاعدة، النسخ الاحتياطي، المتأخرات،
  التعارضات) والتحقق من التحديثات، وسجل تشخيصي قابل للنسخ.
- حواجز أخطاء: خطأ في صفحة لا يُسقط التطبيق، والأعطال تُسجَّل.
- **التحكم بالكمبيوتر** (ويندوز): فتح البرامج والملفات والروابط، لقطة شاشة، النقر
  والكتابة وضغط الاختصارات، التبديل بين النوافذ، تنفيذ أوامر PowerShell، قراءة
  الحافظة والملفات، ومعلومات النظام. يعتمد على ما يوفره ويندوز نفسه بلا وحدات
  أصلية. **الأوامر تتطلب موافقتك** داخل المحادثة (وتستطيع طلب الموافقة قبل كل نقرة).
- **أدوات مهام جاهزة**: خطاب/مذكرة، بريد، تنظيم محضر، تلخيص، ترجمة، تدقيق، خطة
  أسبوعية، تقرير من أرقام، تعميم — واستخراج المهام من أي نص أو محضر.
- اختيار النموذج (Opus 5 افتراضيًا) وعمق التفكير من الإعدادات.

### ✅ المهام والمحاضر

Kanban بسحب وإفلات، أولويات واستحقاق، تفكيك الأهداف بالذكاء الاصطناعي، وأرشيف
محاضر وملاحظات ببحث فوري يفهم العربية.

### 🎨 التصميم

- **ليلي**: خلفية شبه سوداء مع بطاقات باستيل (أزرق، بنفسجي، مرجاني، ليموني) وأزرار
  حبوب وأزرار دائرية.
- **نهاري**: بني/ذهبي الجامعة (#865D24) على خلفية كريمية.
- تخطيط متجاوب: شريط جانبي كامل على الشاشات الواسعة، شريط أيقونات على المتوسطة،
  وشريط سفلي على الهواتف.

### 📱 أندرويد وهواتف الطي

نفس التطبيق (React) يعمل داخل WebView أصلي مع قاعدة بيانات SQLite (WASM) محفوظة
في IndexedDB. يتكيّف مع الشاشة الخارجية والداخلية لهواتف الطي دون إعادة تشغيل،
ويرصد وضع الطاولة (Jetpack WindowManager) فيُبقي المحتوى في النصف العلوي.
التصدير (Excel) يُحفظ في التنزيلات، والـPDF عبر حوار الطباعة الأصلي.

## التشغيل والبناء

المتطلبات: [Node.js 22](https://nodejs.org). لبناء أندرويد محليًا: JDK 17 + Android SDK 34.

```bash
npm install
npm run dev            # ويندوز/سطح المكتب (Electron)
npm run dev:mobile     # واجهة الجوال في المتصفح للتجربة
npm run typecheck
npm run build          # سطح المكتب
npm run build:mobile   # حزمة الجوال (dist-mobile) — تُضمَّن في الـAPK
npm run icon           # توليد أيقونات ويندوز وأندرويد من شعار الجامعة
```

- **ويندوز**: `npm run dist:win` (على ويندوز) أو سير العمل `build-windows.yml` بوسم `v*`.
- **أندرويد**: `npm run build:mobile && cd android && ./gradlew assembleRelease` أو سير
  العمل `build-android.yml` بوسم `android-v*` (يوقّع بمفتاح المستودع إن وُجدت الأسرار
  `MBZUH_KEYSTORE_B64`…، وإلا بمفتاح التصحيح).

## أين تُحفظ البيانات؟

| | ويندوز | أندرويد |
|---|---|---|
| قاعدة البيانات | `%APPDATA%\MBZUH Admin\mbzuh.db` | IndexedDB داخل بيانات التطبيق |
| جلسة البوابات | `%APPDATA%\MBZUH Admin\Partitions\` | CookieManager الخاص بالتطبيق |
| بيانات الدخول ومفتاح API | مشفّرة بـDPAPI | داخل مساحة التطبيق الخاصة |
| النسخ الاحتياطية والتصدير | `backups\` والمستندات | التنزيلات/MBZUH |

لا يُرسل التطبيق بيانات لأي خادم باستثناء طلبات المساعد إلى Claude API واتصال البوابات بمواقعها.

## البنية التقنية

```
├─ electron/        العملية الرئيسية: db · ipc · services (ai, computer, portals, portal-tools, tasks…)
├─ shared/          الأنواع، البوابات الافتراضية، المظهر الحديث، أدوات النص
├─ src/             واجهة React + Tailwind
│  └─ platform/     طبقة الجوال: بدائل electron/node:sqlite (sql.js)/node:fs (VFS) وجسر أندرويد
├─ android/         مشروع أندرويد (WebView + جسر + بوابات أصلية + دعم الطي)
└─ build/           الشعار والأيقونات
```

- **Electron 38** · **React 19** · **TypeScript** · **Vite 7** · **Tailwind 4** · **sql.js** · **@anthropic-ai/sdk**
- البوابات: `WebContentsView` بجلسة `persist:` وحقن CSS، وعلى أندرويد `WebView` + `CookieManager`.
- أمان: `contextIsolation`، جسر IPC محصور، مفاتيح وبيانات دخول مشفّرة بـ`safeStorage`،
  وموافقة المستخدم على أوامر التحكم بالكمبيوتر.
