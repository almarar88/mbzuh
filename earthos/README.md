# مرآة الأرض — EarthOS // Planetary Twin Engine

<div align="center"><strong>تطوير Alcode</strong></div>

تطبيق **أندرويد (APK)** يحاكي كوكب الأرض كتوأم رقمي تفاعلي: كرة أرضية ثلاثية الأبعاد بصور
الأقمار الصناعية الحقيقية من NASA، لوحة تحكم بالمتغيرات المناخية والجيوسياسية، شريط زمني
يمتد ٥٠ سنة للأمام، مصفوفة أثر تنبؤية، ونواة ذكاء اصطناعي (Claude) مربوطة بكل جزء من التطبيق.

## ⬇️ التحميل

- من [صفحة الإصدارات](https://github.com/almarar88/mbzuh/releases?q=earthos) نزّل `EarthOS-1.0.0-release.apk`.
- أو من تبويب **Actions → بناء EarthOS لأندرويد** ثم المُخرَج `EarthOS-APK` لأي دفعة (commit).

بعد التنزيل افتح الملف على الهاتف، وافق على «التثبيت من مصادر غير معروفة» إن طُلب، ثم افتح **EarthOS**.
يعمل التطبيق بالكامل دون إنترنت؛ الإنترنت مطلوب فقط لنواة الذكاء الاصطناعي ولطبقة التكبير عالية الدقة.

> يدعم أندرويد 8 فما فوق، ويتكيّف مع هواتف الطي (Galaxy Z Fold/Flip، Pixel Fold…): في وضع
> **الطاولة** تُعرض الكرة الأرضية على الشاشة العلوية ولوحات التحكم على السفلية، وفي وضع
> **الكتاب** الكرة على اليسار واللوحات على اليمين، ويعاد التخطيط تلقائيًا عند الطي والفتح.

## المكوّنات

| القسم | ماذا يقدّم |
|---|---|
| **الكرة الأرضية** | صور NASA Blue Marble (نهار)، Black Marble 2016 (أضواء المدن ليلًا)، وارتفاعات GEBCO — كلها مضمّنة داخل التطبيق. خط الليل/النهار الحقيقي بحسب توقيت UTC (زر Real Sun)، غيوم، هالة جوية، تيارات محيطية، سلاسل إمداد بين ١٤ ميناء، سُحب كربون. |
| **التكبير عالي الدقة** | عند التقريب يجلب التطبيق مقاطع بدقة ٥٠٠ م من خدمة NASA GIBS (بلا مفتاح)، أو صور VIIRS الحيّة لليوم السابق، أو مقاطع الأقمار الصناعية من Google Maps Platform إن أدخلت مفتاح Map Tiles API في الإعدادات. |
| **لوحة التدخل** | منزلقات: شذوذ الحرارة (٠–٥°م)، ارتفاع البحر (٠–١٠ م)، الغطاء الحرجي (٠–١٠٠٪)، مؤشر اضطراب الشبكة (٠–١٠٠٪). الفيضان يُرسم فعليًا من بيانات الارتفاع (بمبالغة رأسية قابلة للضبط)، وتذوب القمم الجليدية وتَسْمَرّ الغابات وتخفت أضواء المدن بحسب المتغيرات. |
| **الشريط الزمني** | من السنة الحالية إلى +٥٠ سنة، تشغيل/إيقاف، سرعات ١×/٥×/١٠×، وعلامات نقاط الانقلاب المحسوبة للسيناريو الحالي. |
| **مصفوفة الأثر** | النزوح المتوقع، عجز الأراضي الزراعية، درجة استقرار المحيط الحيوي، التعرض الساحلي، نسبة الممرات التجارية العاملة، وسجل الأحداث الحرجة. |
| **السيناريوهات** | ستة سيناريوهات جاهزة (اتفاق باريس، العمل كالمعتاد، الأرض الدفيئة، الانهيار النظامي، التجديد…)، حفظ/تحميل سيناريوهاتك، تصدير واستيراد JSON. |
| **المفتّش** | انقر أي نقطة على الكرة: الإحداثيات، الارتفاع، نوع السطح، حالة الفيضان تحت السيناريو، الشذوذ الحراري المحلي، أقرب ميناء، أضواء الليل، ثم «تقييم إقليمي بالذكاء الاصطناعي» أو «تكبير هنا». |

## نواة الذكاء الاصطناعي

التطبيق يتصل مباشرة بواجهة Anthropic (Claude) من الجهاز. أدخل مفتاح API من **الإعدادات ⚙**
(يُحفظ على جهازك فقط). النموذج الافتراضي `claude-opus-5` ويمكن اختيار Fable 5.1 أو Sonnet 5 أو Haiku 4.5،
مع ضبط الجهد ولغة الرد (عربي/إنجليزي/تلقائي).

| الميزة | أين |
|---|---|
| **محادثة مع التوأم** | تبويب ✦ Intelligence — يرى النموذج لقطة JSON حيّة للسيناريو والسنة والأثر والأحداث مع كل رسالة. |
| **إحاطة تنفيذية** | زر Generate في مصفوفة الأثر — ملخص لصانع القرار بالأرقام المهمة والمناطق الأكثر خطرًا وأعلى رافعة تدخل. |
| **اقتراح تدخل** | زر «AI: Suggest Intervention» — يقترح النموذج إعدادات المنزلقات في كتلة JSON، وزر **Apply** يطبّقها فورًا. |
| **شرح الأحداث** | زر ✦ بجانب أي حدث حرج — شرح الآلية الواقعية وأثرها الثانوي في ثلاث جمل. |
| **تقييم إقليمي** | من المفتّش — يحدد المكان من الإحداثيات ويقيّم تعرضه (فيضان، حرارة، غذاء، بنية تحتية). |

بدون مفتاح يعمل **محلل محلي** مدمج (قوالب حتمية بالعربية أو الإنجليزية) كي لا تتعطل أي ميزة.

## البنية

```
earthos/
├── www/                 # تطبيق الويب (يعمل أيضًا مباشرة في المتصفح بفتح index.html)
│   ├── index.html · css/app.css
│   ├── js/earth.js      # Three.js + شيدر السيناريو + طبقة التكبير عالية الدقة
│   ├── js/ai.js         # عميل Anthropic Messages API (بث SSE) + المحلل المحلي
│   ├── js/app.js        # نموذج الأثر، الواجهة، الشريط الزمني، المفتّش، جسر أوضاع الطي
│   ├── assets/          # صور NASA/GEBCO المضمّنة (~٤.٥ م.ب)
│   └── lib/three.min.js
└── android/             # مشروع Gradle: WebView + WebViewAssetLoader + Jetpack WindowManager (الطي)
```

### البناء محليًا

```bash
cd earthos/android
./gradlew assembleRelease        # يحتاج JDK 17+ و Android SDK 34
# الناتج: app/build/outputs/apk/release/EarthOS-1.0.0-release.apk
```

التوقيع: إن وُجدت أسرار المستودع `EARTHOS_KEYSTORE_B64` و`EARTHOS_KEYSTORE_PASSWORD` و`EARTHOS_KEY_ALIAS`
و`EARTHOS_KEY_PASSWORD` يُوقَّع الإصدار بها، وإلا يُستخدم مفتاح التصحيح (يُثبَّت عاديًا، لكن التحديث فوق
نسخة موقّعة بمفتاح مختلف يتطلب إزالة القديمة أولًا).
