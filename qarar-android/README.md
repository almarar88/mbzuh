# قرار — مستشار القرارات الشخصي بالذكاء الاصطناعي

<div align="center"><strong>تطوير Alcode</strong></div>

تطبيق أندرويد يساعدك على اتخاذ قرارات أفضل، ثم يعلّمك من نتائجها.
لا يجيب «افعل كذا» وحسب؛ يكشف **الافتراضات الخفية** التي تبني عليها، يقترح **خيارات لم تخطر لك**،
يشرّح مخاطر كل مسار وآثاره من الدرجة الثانية، ينفّذ تحليل **«ما قبل الفشل»**، ثم يوصي بخيار واحد
مع **نسبة ثقة صادقة**. وبعد أن تقرر وتمرّ المدة، يقارن ما توقعته بما حدث فعلًا، ويفصل
**جودة القرار عن جودة الحظ**، ويرصد **تحيزاتك المتكررة** عبر كل قراراتك.

## الفكرة في سطر

> «سجل قرارات» (Decision Journal) — الأداة التي يستخدمها المستثمرون وصنّاع القرار المحترفون — مدمج
> بمستشار ذكاء اصطناعي لا يجامل، في جيبك، وبالعربية.

## ما الذي يفعله

| المرحلة | ما يحدث |
|---|---|
| **اكتب المعضلة** | العنوان، السياق كما هو في رأسك، الخيارات (2–6)، درجة الأهمية (بسيطة/متوسطة/مصيرية)، موعد نهائي اختياري. |
| **التحليل الذكي** | المشكلة الحقيقية خلف السؤال · الافتراضات الخفية · خيارات ناقصة · تشريح كل خيار (إيجابيات، سلبيات، مستوى الخطر، «ثم ماذا؟») · ما قبل الفشل · أسئلة يجب أن تجيب عنها · هل القرار قابل للتراجع؟ · توصية بنسبة ثقة. |
| **سجّل قرارك** | ما اخترت (يُقارن بالتوصية تلقائيًا)، لماذا، ما تتوقع أن يحدث، ومتى تراجع النتيجة. |
| **المراجعة** | بعد حين: ما حدث فعلًا وتقييمك من 5. ثم مراجعة ذكية: هل كان قرارًا جيدًا أم نتيجة جيدة فقط؟ أي تحيزات أثّرت؟ ما الدرس؟ |
| **أنماطك** | إحصاءات محلية (التزامك بالتوصية، نتائجك حين وافقتها مقابل حين خالفتها، نتائج القرارات المصيرية…) + تحليل ذكاء اصطناعي لأنماطك وتحيزاتك عبر كل قراراتك. |

## الخصوصية

- كل البيانات على جهازك في ملف JSON داخل تخزين التطبيق الخاص. لا حسابات، لا خادم، لا تتبّع.
- نصوص القرار تُرسل إلى Anthropic فقط عند طلب تحليل، ومن الجهاز مباشرة إلى `api.anthropic.com`.
- مفتاح API يُحفظ في التخزين الخاص ويُستثنى من النسخ الاحتياطي السحابي.

## التثبيت

1. نزّل `Qarar-*.apk` من [صفحة الإصدارات](https://github.com/almarar88/mbzuh/releases) (أو من مُخرَجات GitHub Actions).
2. ثبّته على هاتف بأندرويد 8.0 فأعلى (قد يطلب السماح بالتثبيت من مصادر غير معروفة).
3. من **الإعدادات** أدخل مفتاح Claude API (`sk-ant-…`) من [console.anthropic.com](https://console.anthropic.com/settings/keys) واضغط «اختبار الاتصال».

## التقنية

- Kotlin · Jetpack Compose · Material 3 · خط Tajawal · واجهة RTL كاملة · ثيم داكن/فاتح تلقائي.
- الذكاء الاصطناعي: Claude Messages API مباشرة عبر OkHttp مع **المخرجات المنظمة** (JSON Schema) حتى لا تُعرض أبدًا إجابات حرّة غير منسّقة؛ النموذج الافتراضي `claude-opus-5` مع تفكير تكيّفي وتحكّم في عمق التفكير (`effort`)، وتفعيل `fallbacks: "default"` لتفادي الرفض، ودعم `claude-sonnet-5` و`claude-haiku-4-5`.
- التخزين: مستودع JSON محلي (بلا قاعدة بيانات) — كافٍ لآلاف القرارات.
- الاختبارات: اختبارات وحدات للنماذج والمخططات، واختبارات Robolectric تشغّل التطبيق الحقيقي على JVM وتمرّ بالتدفق الأساسي (التعريف → الرئيسية → قرار جديد → التفاصيل → الإعدادات).

## البناء محليًا

```bash
cd qarar-android
# يتطلب JDK 17+ و Android SDK (platforms;android-35, build-tools;35.0.0)
gradle testDebugUnitTest          # الاختبارات
gradle assembleRelease            # APK موقّع في app/build/outputs/apk/release/
gradle testDebugUnitTest -Pscreens --tests 'com.alcode.qarar.ScreenshotTest'   # لقطات شاشة في app/build/screens/
```

مفتاح التوقيع في `keystore/` (مفتاح هواة بكلمة مرور في `keystore.properties`) كي تُثبَّت التحديثات فوق الإصدارات السابقة
من أي جهاز بناء. لنشر عام على المتجر استبدله بمفتاح خاص عبر متغيرات البيئة `QARAR_KEYSTORE`, `QARAR_KEYSTORE_PASSWORD`, `QARAR_KEY_ALIAS`, `QARAR_KEY_PASSWORD`.
